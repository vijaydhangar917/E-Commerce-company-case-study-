# E-Commerce-company-case-study

## Project Overview
This project focuses on analyzing an e-commerce company's customer, product, order, and sales data using SQL.
The objective is to understand customer purchasing behavior, product performance, sales trends, customer acquisition, and business growth opportunities through data-driven insights.

## Dataset Information
The project contains the following tables : 
- Customers
- Orders
- Orderdetails
- Products

## Tools and Technologies
- MySQL
- SQL
- Mysql workbench

## SQL Concepts Used
- SELECT statement
- WHERE clause
- GROUP by
- HAVING
- ORDER BY 
- AGGREGATE functions
- Common Table Expressions
- subqeries

## Detailed business questions, insights,queries are available in the project documentation file.

## Conclusion 
The analysis helped identify customer purchasing patterns, high-performing products, product category demand, monthly sales fluctuations, customer acquisition trends, and inventory turnover.These insights can help an e-commerce company improve marketing strategies, customer retention, inventory planning, and overall business performance.Through this project, I enhanced my practical knowledge of SQL, data analysis, and converting raw data into actionable business insights.
